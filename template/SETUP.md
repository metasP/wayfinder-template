# ดูแล vault นี้ — อัปเดต · ตรวจสุขภาพ

vault นี้เป็น **installation อันหนึ่ง** ของ wayfinder template ไม่ใช่ต้นฉบับ
ต้นฉบับคือ repo ที่คุณ clone มาตอนติดตั้ง (เรียกในหน้านี้ว่า `<wayfinder-template>`)

> **ติดตั้งครั้งแรก ไม่ได้อยู่ในหน้านี้** — อยู่ที่ `INSTALL.md` ใน repo
> หน้านี้คือของที่ทำ *หลัง* ติดตั้งเสร็จแล้ว

---

## อัปเดต

```bash
cd <wayfinder-template>
git pull
```

แล้วบอก agent ว่า **"อัปเดต wayfinder จาก repo นี้"** — คำสั่งเป๊ะ ๆ อยู่ใน `INSTALL.md` ของ repo
(หน้านี้ไม่จดไว้ซ้ำ เพราะสำเนาที่สองของคำสั่งคือของที่ drift เป็นอันดับแรกเสมอ)

**ทับทั้งชุด ไม่ถามทีละไฟล์** — สามโน้ตกับ `_tools/` เป็นหน่วยเดียวกัน (โน้ตหนึ่งอ้างค่าคงที่ของอีกโน้ต
และ `doctor.mjs` เช็คว่ามันตรงกัน) ทับครึ่ง ๆ = ได้ vault ที่ `doctor` ตกโดยไม่มีใครแตะอะไรผิดเลย

### ของคุณ ที่การอัปเดตไม่แตะ

| | |
|---|---|
| `<repo>/<effort>/` ทุกโฟลเดอร์ | งานจริงของคุณ — map, ticket, assets |
| `Wayfinder Config.md` | ค่าที่คุณจูน: เส้นแบ่ง "นิ่งมานาน", สี, ป้ายสถานะ |
| `Wayfinder Picks.md` | กฎ "หยิบอันไหนต่อ" ที่คุณเขียนเอง |
| `.obsidian/workspace.json` | เลย์เอาต์ pane ของเครื่องคุณ (ไม่ถูก track อยู่แล้ว) |
| ของแปลกปลอมที่คุณเพิ่มเอง | ตัวอัปเดตเดินตามรายชื่อไฟล์ของ template เท่านั้น |

⇒ ปรับค่าอะไรก็ตาม **ปรับใน `Wayfinder Config.md`** ไม่ใช่ในบล็อกโค้ดของสามโน้ต
ของที่แก้ในสามโน้ตจะหายในการอัปเดตครั้งถัดไป และนั่นคือพฤติกรรมที่ตั้งใจ

## ตรวจสุขภาพ

```bash
node _tools/doctor.mjs
```

exit 0 = ผ่านหมด · ไม่ต้องเปิด Obsidian

นอกจากตรวจการติดตั้ง `doctor.mjs` ยัง **ลินต์เนื้อ vault** ให้ด้วย — ทุก ticket/map มี `status` +
`status_since` ที่ถูกต้อง · map ที่ไม่เดินมี `status_note` บอกเงื่อนไขกลับมา · `blocked_by`/
`superseded_by` ไม่ห้อย · ไม่มีใบค้างใน map ที่ประกาศว่าปิดแล้ว · และไม่มี map ที่สถานะขัดกับ
ความเคลื่อนไหวของใบ (ประกาศว่า `paused`/`dropped`/`done` ไว้ แต่มีใบขยับหลังวันที่ประกาศ = สถานะเน่า)

**เหลือ 2 ข้อที่เครื่องตรวจแทนไม่ได้ ต้องเปิด Obsidian ดูเอง:**

- Dashboard ทุก view เรนเดอร์เป็น **ตาราง** และ Efforts เรนเดอร์เป็น **แถบสี** ไม่ใช่กล่องแดง
  `Dataview: <error>` หรือโค้ดดิบ (ว่างแล้วขึ้น `No results to show` = ปกติ ไม่ใช่พัง)
- Graph View ระบายสี node ตาม status จริง — แมปที่ `paused`/`draft`/`dropped` ต้องได้สีของตัวเอง
  ไม่ใช่สีฟ้าของแมปทั่วไป

## เจอปัญหา

**สี Graph View หายหลังเปิด Obsidian ทิ้งไว้**

```bash
git checkout .obsidian/graph.json
```

⚠️ **ปิด Obsidian ให้สนิท (`Cmd+Q`) ก่อนเสมอ** — ตราบใดที่มันเปิดอยู่ ไฟล์ใน `.obsidian/` เป็น
**output ของมัน ไม่ใช่ input**: มันถือ setting ไว้ในหน่วยความจำแล้ว flush ทับดิสก์ (เคยเขียน
`colorGroups` ตอนเปิดอยู่แล้วโดน revert กลับมาแล้ว)

**นาฬิกา "นิ่งมากี่วัน" ดูเพี้ยนหลังย้ายเครื่อง** — ไม่เพี้ยน ทุกอย่างอ่านจาก `status_since` ใน
frontmatter ซึ่งเป็นเนื้อไฟล์ ⇒ เดินทางไปกับ git · (git ไม่เก็บ `mtime` — ถ้าวันไหนมีอะไรกลับไป
อ่าน `mtime` นั่นคือบั๊ก)

**agent เขียน map ลง `docs/plan/` ของ repo งาน แทนที่จะลง vault นี้** — ย่อหน้า wayfinder ใน
`~/.claude/CLAUDE.md` หายไป ดูวิธีต่อกลับใน `INSTALL.md` ของ repo

**แก้ ticket แล้ว `git log` ของ vault ไม่ขยับ** — PostToolUse hook ไม่ทำงาน
`doctor.mjs` มีข้อตรวจเรื่องนี้อยู่ รันมันก่อนเป็นอย่างแรก
