## Question

**ลบ `example-repo/` ทิ้งเมื่อไม่ต้องการอ้างอิงมันแล้ว**

ใบนี้เป็น `open` เหมือนใบ 02 แต่ไปโผล่คนละที่ — มันมี `blockers` ที่ชี้ไปใบซึ่งยังไม่ `resolved`
⇒ หลุดจาก 🔥 Frontier ไปอยู่ 🚧 Blocked แทน · **`blocked` ไม่ใช่ค่าสถานะ** มันถูกคำนวณจาก
`blockers` ทุกครั้งที่ query รัน ⇒ วินาทีที่คุณปิดใบ 02 ใบนี้ย้ายมา Frontier เอง ไม่ต้องไปแก้อะไรที่นี่

### ทำไมถึงติดใบ 02 จริง ๆ ไม่ใช่ผูกไว้ให้ดูเป็นตัวอย่าง

นี่คือสำเนาเดียวของรูปแบบที่ **ผ่าน lint จริง** อยู่บนเครื่องคุณ · ลบก่อนได้ชาร์ต map ของตัวเอง
สักอันก็คือทิ้งของอ้างอิงตอนที่ยังต้องใช้มันที่สุด — ซึ่งเป็นเหตุผลเดียวกับที่ blocker มีอยู่ในระบบนี้
ตั้งแต่แรก: **ลำดับที่ผิดทำให้งานแพงขึ้น ไม่ใช่ทำให้งานทำไม่ได้**

### ทำยังไง

ลบทั้งโฟลเดอร์ `example-repo/` ที่รากของ vault

```bash
rm -rf example-repo
```

> **agent ลบไฟล์ใน vault ให้ไม่ได้** — vault อยู่นอก sandbox ⇒ `rm` ถูกปฏิเสธด้วย
> `Operation not permitted` · บรรทัดนี้ต้องรันเอง

### ลบแล้วมันจะไม่กลับมา

`example-repo/` อยู่ในชั้น **seed-once** ของ manifest ไม่ใช่ชั้น managed ⇒ installer วางมันครั้งเดียว
ตอนติดตั้ง แล้ว **update ไม่แตะมันอีกเลย** ทั้งทับและปลุกคืน · ต่างจากสามโน้ต `Wayfinder *.md`
กับ `_tools/` ที่ update ทับทุกรอบเพราะเป็นของ template

เส้นแบ่งนี้เป็น**เชิงโครงสร้าง** ไม่ใช่การเดาตอน runtime — `.wayfinder-template.json` ที่รากของ vault
แยก `files` (ทับ/ลบได้) ออกจาก `seeded_once` (วางครั้งเดียว) ไว้คนละคีย์ และ installer ตรวจตอนสร้าง
manifest ว่าไฟล์เดียวกันห้ามอยู่ทั้งสองฝั่ง

**ผลข้างเคียงที่ควรรู้:** ถ้าลบแล้วอยากได้คืน update เอาคืนให้ไม่ได้ — ต้องก็อบจาก
`template/example-repo/` ในโคลนของ repo ต้นฉบับเอง
