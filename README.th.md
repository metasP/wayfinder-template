# wayfinder-template

> **🚧 ยังเป็น stub — ไฟล์นี้เขียนโดยใบ `07-readme-bilingual`**
> โครงรอบ ๆ เป็นของจริงครบแล้ว ขาดแค่หน้านี้กับคู่ภาษาอังกฤษ (`README.md`)

**ตัวติดตั้ง/template** สาธารณะของ wayfinder — Obsidian vault + issue tracker ที่เป็น markdown
ในเครื่อง สำหรับสกิล `/wayfinder` โดยที่ map และ ticket ของ **ทุก repo รวมอยู่ที่เดียว** ซึ่งอยู่
*นอก* repo งาน ⇒ map ไม่ตายไปพร้อม branch หรือ worktree ที่ถูกลบ

## มีอะไรอยู่ในนี้

| path | คืออะไร |
|---|---|
| `template/` | ตัว vault เป๊ะ ๆ อย่างที่ควรอยู่บนดิสก์ · **ทุกอย่างในนี้ถูกทับทั้งชุดตอนอัปเดต** ⇒ อย่าไปแก้ในvault ของตัวเอง |
| `skills/` | สกิล `/wayfinder` และ `/wayfinder-next` ที่ installer จะวางให้ |
| `INSTALL.md` | วิธีติดตั้งและอัปเดต · **เริ่มที่นี่** (ยังเป็น stub — ใบ `08`) |
| `LICENSE` | MIT |
| `THIRD-PARTY.md` | ของที่ ship ติดไปด้วยหนึ่งตัว (Dataview) กับ license ของมัน |

`template/example-repo/` คือ effort ตัวอย่างที่ ship **ตอน install เท่านั้น** — ใบ `06` เป็นคนเขียน
ตอนนี้ยังเป็นโฟลเดอร์เปล่า
