A public **installer/template** for wayfinder: an Obsidian vault plus a local-markdown
issue tracker for the `/wayfinder` skill, where every repo's maps and tickets live in one
place — outside the repos themselves, so a map never dies with a branch or a worktree.

## What's in here

| Path | What it is |
|---|---|
| `template/` | The vault, exactly as it should exist on disk. Everything here is **overwritten wholesale on update** — never edit it in your own vault. |
| `skills/` | The `/wayfinder` and `/wayfinder-next` agent skills the installer places for you. |
| `INSTALL.md` | Install and update instructions. **Start here.** (stub — ticket `08`) |
| `LICENSE` | MIT. |
| `THIRD-PARTY.md` | The one vendored component (Dataview) and its license. |

`template/example-repo/` is a worked example effort shipped **on install only** — it is
written by ticket `06` and is currently an empty placeholder.
